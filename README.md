\# Домашнее задание 14: Асинхронная система уведомлений



\## Описание

Программа имитирует работу системы уведомлений, которая асинхронно отправляет уведомления разным пользователям с разными задержками.



\## Функциональность

\- Асинхронная отправка уведомлений с использованием `asyncio`

\- Конкурентное выполнение задач с помощью `asyncio.gather`

\- Поддержка пустого списка пользователей (без ошибок)



\## Установка и запуск



\### Требования

\- Python 3.7+



\### Запуск

```bash

python notifications.py
